# Mechanistic-models-for-human-mobility
# Моделирование дневной плотности населения на основе механистических моделей на примере Хельсинки

Дневная плотность населения является одной из важнейших метрик для анализа городских систем. Ее анализ полезен для планирования городских территорий, оценки рисков опасных явлений природного и техногенного характера и оптимального размещения объектов социальной, экономической и транспортной инфраструктуры. 

## Используемые данные 

Агрегированные сеточные данные мобильных операторов с разрешением 500 на 500 метров о 24-часовом распределении населения в Столичном регионе города Хельсинки (Финляндия) 
https://zenodo.org/records/6106064


## Используемые модели

Радиационная модель (Simini et al., 2012)  и модели промежуточных возможностей: модель выбора приоритетных возможностей (Liu et al., 2019) и модель возможностей, взвешенных по численности населения (Yan et al., 2014)
